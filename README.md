# Batchmate (working name)

A community site for freshers moving to Bengaluru: joining dates by batch, flatmates and PGs near
the office, and people from the same company, area or hometown.

This first version is a validation experiment. Start with `CLAUDE.md` and `docs/VALIDATION.md`.

## Run locally

```
pnpm install
cp .env.example .env.local
pnpm dev
```

Checks: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:e2e`.
